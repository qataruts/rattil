# مشروع رَتِّلْ — عائلة تطبيقات التأسيس

سابعُ العائلة عملاً وفاتحُ الفرع القرآني: تعليمُ التجويد لطفلٍ أتمّ «اقرأ».
**المشروع قبل بوابته**: وثائقُ ولايةٍ ودراسةٍ فقط — لا شيفرة ولا منهجَ بعد.
ابدأ من `CLAUDE.md` (الحالة والعهود) ثم `docs/MANDATE.md` (الولاية)
ثم `docs/STUDY_BRIEF.md` (تكليف الدراسة).
